# Dicionários originais

Os arquivos `en.json` e `zh.json` preservam os dicionários completos importados do projeto Cordova AirLock na primeira entrega, inclusive textos de funcionalidades ainda não migradas. As menções ao hardware foram atualizadas para BJJ-Cold-Wallet.

Os catálogos ativos de BJJ-App-Wallet são XMLs de Compose Resources, em `shared/src/commonMain/composeResources/values/strings.xml` e nas pastas `values-pt`, `values-zh`, `values-es`, `values-fr`, `values-it`, `values-de`. Estes JSONs históricos não são empacotados nem carregados pelo aplicativo. A autoria e a licença dos recursos originais estão registradas em `NOTICE.md` e `LICENSE` na raiz do projeto.
