# Como contribuir

Contribuições são bem-vindas por **pull request (PR)**. Toda alteração destinada à branch `main` deve passar por um PR e pela revisão dos mantenedores.

1. Crie um fork e uma branch para sua alteração.
2. Faça uma alteração com escopo claro e execute as verificações pertinentes descritas no [app](app/README.md) ou no [hardware](hardware/README.md).
3. Abra um PR para `main`, explicando o problema, a solução e como ela foi validada.
4. Aguarde a revisão e resolva as observações antes da incorporação.

Siga os [padrões de código](docs/CODE_STYLE.md) e preserve as licenças e atribuições dos componentes utilizados.

Nunca envie seeds reais, chaves privadas, PINs, Transaction Phrases, credenciais, backups de dispositivos ou dados de carteiras em commits, issues, PRs, logs ou capturas de tela. Use somente dados de teste públicos e identificados como tal.

## Contributing

All changes to `main` must go through a **pull request** and maintainer review. Fork the repository, create a focused branch, run the relevant checks documented for the app or hardware, and describe your change and validation in the PR. Follow the project's code style and preserve licenses and attribution. Never submit real wallet secrets, credentials, device backups, or private wallet data; use clearly identified public test fixtures only.
